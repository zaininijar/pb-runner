# Komponen pihak ketiga

Repository ini hanya menyertakan source runner Rust, antarmuka SwiftUI, build script, dokumentasi, dan source probe diagnostik. Runtime Wine, Wine Mono, MoltenVK, Vulkan Loader, DXVK/D9VK, unixODBC, libltdl, Winetricks, cabextract, installer Microsoft, dan client/launcher PB tidak didistribusikan dalam Git repository.

Jika membangun aplikasi lokal dengan komponen tersebut, pertahankan lisensi dan pemberitahuan upstream yang menyertai paketnya. Wine dan sebagian komponennya berlisensi LGPL; DXVK/D9VK memakai lisensi Zlib; komponen lain memiliki lisensi upstream masing-masing. Client PB dan Z-Launcher adalah milik Zepetto. Source runner baru tidak mengubah lisensi komponen tersebut.

PB Runner tidak berafiliasi dengan Zepetto, WineHQ, CodeWeavers, Sikarugir, atau Apple.
